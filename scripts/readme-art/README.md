# README artwork

The root README uses a matching set of screenshot cards and looping previews
in `assets/readme/`. `layout.html` is the editable source for the typography,
window frames, and composition. It uses the existing Opal logo and real app
captures; interface pixels are not generated by AI.

`assets/readme/opalescent.webp` is an AI-generated abstract backdrop made for
this README. Keep it in the repository so exports do not require generation
or a network connection.

## Refresh the exports

Install the ego-browser CLI, FFmpeg, and ImageMagick. Import the renderer with
the absolute path to your checkout:

```sh
ego-browser nodejs -e 'await import("file:///path/to/Opal/scripts/readme-art/render.mjs")'
```

The renderer derives the repository path from its own file, captures the HTML
at a fixed viewport, exports WebP stills, and frames the original MP4 recordings
with FFmpeg. It prints its temporary capture directory for visual inspection.
The source captures in `assets/screenshots/` and `assets/media/` stay intact.

Browse and AI previews use 8 fps at 960 px wide; torrent playback uses 6 fps
at 800 px wide to keep the video-heavy GIF smaller. README links open the
original MP4 recordings for smoother playback. Every GIF loops indefinitely.
Text in the artwork is also represented by accessible README text and alt text.

The GIF recordings predate the refreshed desktop toolbar shown in the stills.
Replace the source recordings when new demos are captured, then run the renderer.
Preserve the Blender Foundation / CC BY 3.0 credits for Sintel and Big Buck Bunny.

Before finishing, check the exports at their displayed README size, confirm
local image and video links exist, and run `git diff --check`.
